Install BoosterAI

Single self-contained executables. Zero dependencies or runtimes needed.

Download BoosterAI for Windows (.zip)

Unpack the zip and run the installer script in PowerShell (no administrator rights needed):

powershell -ExecutionPolicy Bypass -File install-windows.ps1

Places BoosterAI in %LOCALAPPDATA%\Programs\BoosterAI, registers Start menu & desktop shortcuts, and restarts in the background.

💡 Windows SmartScreen notice: If Windows warns that the app is unrecognized, click More info and then Run anyway (SignPath open-source code signing verification in progress).
Download BoosterAI for Linux (.tar.gz)

Extract the release tarball and run the install script:

tar -xzf BoosterAI-*-linux-x64.tar.gz && ./BoosterAI-*-linux-x64/install-linux.sh

Installs binary to ~/.local/bin and adds desktop menu entries with native desktop icons.
