Projects, Subtabs and Six AI CLIs

Start selected projects in their saved directories with individual tab titles and colours. Add subtabs sharing a project folder, each with its own CLI and model. Status refreshes every two seconds while BoosterAI watches the tabs.

⚡ Claude Code ⚡ Codex CLI ⚡ Antigravity (AGY) ⚡ Aider ⚡ Open Interpreter ⚡ OpenHands 💻 Plain Bash shell
🧠

Models & Context Budgets

Choose a model per tab or keep the CLI default. Apply a model change with an explicit restart; Claude, Codex and Aider can keep the conversation when its directory is unambiguous. Under Memory and context → Context, choose Off, Clear when idle or Summarize. Summarize offers Auto or Manual budgets; Auto uses known model capacity and an explained reserve.

👁️

Live Peek & Terminal Pulse

Hover over a running tab's status badge, or focus it and press Enter or Space, to inspect its last 20 output lines. Activity detail depends on the CLI; unknown activity is shown explicitly.

Orchestra on Demand

Full native integration with Dirigenten och orkestern. For projects with the orchestra installed, send its startup instruction to your selected CLI (the repository skill in Codex when available). Choose Run once for a non-interactive session, or reload an idle interactive Claude orchestra without restarting its tab.

RAM Usage & WSL Memory Limits

On Windows, see current WSL resident RAM and sampled minimum, mean and maximum over a rolling 30-minute window. Review the suggested memory-cap range and save it to .wslconfig; restart WSL to apply a change. Native Linux shows system memory; WSL caps apply only on Windows.

Save Work Before Closing

Close all asks safely resumable Claude, Codex, AGY and Aider sessions to save, commit and push completed work before closing. Other agents and ambiguous shared conversations stay open for manual saving. Permissions or a failed save can prevent closure; force close is an explicit separate action.

Install BoosterAI

Guided Windows setup or a small Linux install script. No .NET runtime to install.

Windows needs Windows Terminal and a working WSL distribution; Linux uses an installed supported terminal. Install the AI CLIs you want to run and complete any required sign-in or local-model setup. Platform details.

Get Windows setup from the latest release

Choose BoosterAI-Setup-*-win-x64.exe under the release's assets. It installs for your Windows user, with no administrator rights needed.

  1. Run the setup file.Open the downloaded executable to begin the guide.
  2. Choose your settings.Pick the language, appearance and AI CLI for projects you add.
  3. Find your projects.Choose a base folder to search and select which projects to add.
  4. Install and open BoosterAI.The app starts in the background, ready on your Start menu and desktop.

Every step before installation can be skipped. The app goes in %LOCALAPPDATA%\Programs\BoosterAI, with Start menu and desktop shortcuts.

Already using BoosterAI?

Run a newer setup over your existing installation; no uninstall is needed. Your projects and settings are kept, and skipped choices change nothing. The app's built-in updates remain available.

Need to uninstall?

Choose BoosterAI in Windows Settings → Apps → Installed apps. Uninstalling removes the program and shortcuts while keeping your configuration and session data.

Zip alternative and silent deployment

Alternatively, extract BoosterAI-*-win-x64.zip from the latest release and run the installer script in PowerShell:

powershell -ExecutionPolicy Bypass -File install-windows.ps1

For scripted or IT deployment, add --quiet to the setup executable. It installs without a window and keeps the existing configuration. Setup command reference.

💡 Windows code signing: Releases are signed by Svep Design Center AB. SmartScreen can still warn about a new release while it builds reputation; check the publisher before choosing More info and then Run anyway. About SmartScreen prompts.
Download BoosterAI for Linux (.tar.gz)

Extract the release tarball and run the install script:

tar -xzf BoosterAI-*-linux-x64.tar.gz && ./BoosterAI-*-linux-x64/install-linux.sh

Installs binary to ~/.local/bin and adds desktop menu entries with native desktop icons.
